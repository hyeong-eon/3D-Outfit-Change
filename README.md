# 3D-Outfit-Change

신체 치수와 옷 사이즈표를 입력하면 아바타에 옷을 입혀 보고, 부위별 핏을 판정해 주는 가상 피팅룸입니다.
GPU나 유료 API 없이 **브라우저 안에서만** 동작합니다 (서버 없음).

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 핏 계산·도형 테스트
npm run build    # 배포용 빌드 (dist/)
```

## 기능 (2D 프로토타입)

- **신체 치수 입력** — 키, 목둘레, 어깨너비, 가슴·허리·엉덩이둘레, 상체길이, 팔길이, 팔뚝·손목둘레, 다리길이, 허벅지·종아리·발목둘레. 남/여 평균값 프리셋.
- **치수 기반 마네킹** — 입력값대로 체형이 바뀌는 이목구비 없는 마네킹입니다.
- **옷 템플릿** — 반팔/긴팔 티셔츠, 긴바지, 반바지, 스커트. S~XL 기본 사이즈를 고르거나 쇼핑몰 사이즈표 실측값(총장, 단면 등)을 직접 입력.
- **옷 사진 → 디자인** — 사진을 올리면 단색 배경을 자동으로 지우고 옷 색을 추출합니다. "앞판에 맞추기"(프린트 티셔츠 등) 또는 "원단 패턴"(반복 무늬)으로 입힙니다.
- **핏 분석** — 부위별로 신체와 옷 치수를 비교해 작음 / 꼭 맞음 / 적당 / 여유 / 과함으로 판정하고, 아바타 위에 히트맵으로 표시. 템플릿 기준 추천 사이즈 표시.
- **옷장** — 만든 옷을 저장해 두고 다시 입히기 (브라우저 localStorage).

## 구조

```
src/
  model/       치수 타입·프리셋(body), 옷 템플릿·사이즈표(garments), 핏 판정(fit)
  geometry/    치수 → 정면 도형 계산. UI와 무관한 순수 함수 (3D에서도 재사용 예정)
    body.ts      신체 랜드마크·둘레→폭 변환·팔/다리 축
    garment.ts   옷 실루엣(입었을 때 폭, 드롭숄더, 기장 쌓임 등)
  components/  React UI (Avatar2D가 SVG 렌더러)
  lib/         사진 처리(배경 제거·색 추출), localStorage 훅
```

핏 계산의 핵심 가정:
- 몸과 옷의 단면을 타원으로 보고 둘레 → 정면 폭으로 변환합니다. 옷이 클수록 납작해져 넓게 떨어집니다.
- 어깨선은 `(옷 어깨너비 − 몸 어깨너비) / 2` 만큼 팔 쪽으로 내려가고, 소매 길이는 그 지점부터 잽니다.
- 바지는 밑위 길이에 맞춰 허리 위치가 정해지고, 바닥보다 길면 밑단에 주름이 쌓입니다.
